# 📊 MacroGold Analytics

MacroGold Analytics es una herramienta interactiva que analiza el impacto de eventos macroeconómicos en el precio del oro. Utiliza datos históricos y técnicas de visualización para ayudar en la toma de decisiones financieras.

## 🚀 Funcionalidades Principales
- 📈 **Visualización del Precio del Oro**: Análisis interactivo con filtros de fechas.
- 🌍 **Impacto de Eventos Macroeconómicos**: Comparación del oro antes y después de eventos clave.
- 📉 **Análisis de Volatilidad**: Evaluación de la variabilidad del oro antes y después de eventos.
- 📊 **Media Móvil del Oro**: Identificación de tendencias a corto, mediano y largo plazo.
- 🔄 **Correlación con el Dólar (DXY)**: Relación entre el precio del oro y el índice del dólar.
- 📝 **Generación de Informes PDF**: Exporta reportes personalizables con datos clave.
